# Samuel Hult – artisthemsida

En responsiv, statisk artisthemsida på svenska. Den fungerar på GitHub Pages utan byggsteg.

## Innan publicering

Uppdatera `index.html` med Samuels YouTube-länkar och en fungerande bokningsadress eller annan kontaktväg. Lägg gärna till en egen pressbild och domän. Publicera inte innan kontaktväg och önskade musiklänkar har lagts till.

## Publicera via GitHub Pages

1. Öppna repositoryts **Settings → Pages**.
2. Under **Build and deployment**, välj **Deploy from a branch**, välj `main` och `/ (root)`, och spara.
3. När GitHub Pages visar att publiceringen är klar får du en `github.io`-adress.
4. För en egen domän: ange domänen i **Settings → Pages → Custom domain**.
5. Lägg in DNS-posterna hos domänleverantören enligt GitHub Pages-anvisningarna. Följ GitHubs aktuella dokumentation för rätt DNS-värden.
6. När DNS har hunnit uppdateras, aktivera **Enforce HTTPS** i Pages-inställningarna.

Guide: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site

## Sökmotoroptimering

Sidan har svensk språkdeklaration, sidtitel, beskrivning, Open Graph-metadata och strukturerade personuppgifter. Google behöver hitta och indexera den publicerade sidan; sökresultat kan dröja och en viss placering kan inte garanteras.
